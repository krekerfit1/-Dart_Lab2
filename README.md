# Лабораторная работа №2: Классы и объекты в Dart

Консольное CLI-приложение **ToDo**, разработанное на Dart в рамках изучения концепций ООП.

---

## 🎯 Цели и задачи
* **Изучение ООП:** работы с классами, объектами, полями, конструкторами и методами в Dart.
* **Особенности Dart:** использование null-safety, именованных параметров конструктора и переопределение метода.
* **Практика:** создание интерактивного консольного менеджера задач.

---

## 🚀 Функционал и команды

| Команда | Описание |
| :--- | :--- |
| `add` | Добавить новую задачу в список |
| `list` | Отобразить все текущие задачи с их статусами |
| `done` | Отметить задачу как выполненную (по ID) |
| `delete` | Удалить задачу из списка (по ID) |
| `exit` | Завершить работу приложения |

---

## 💻 Пример работы

```text
=== ToDo App ===
Доступные команды: add, list, done, delete, exit

> add
Введите название задачи: Купить продукты
Задача добавлена!

> list
[ ] 1. Купить продукты

> done
Введите ID задачи: 1
Задача #1 выполнена!

> list
[x] 1. Купить продукты
